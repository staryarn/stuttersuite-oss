# StutterSuite

StutterSuiteは、通話や発表で使う音声・リズム・原稿の補助を、ブラウザ内で調整する開発中のツールです。音声は端末内で処理します。診断や治療を行うものではなく、効果を保証しません。

主な機能は、遅延・音程の調整（DAF・FAF、2系統対応）、ノイズ、自声モニター、メトロノーム、原稿の句分割と読み上げ（TTS）、斉読、設定の保存、補助なしを含む条件比較、振り返りの記録、出力先の選択、緊急停止、小型パネル、JSONバックアップ・復元です。

「音声補助」はカスタム設定に統一しています。加工音声A・Bの追加遅延、音程、相対ゲイン、左右の出力を直接調整し、必要な機能だけ有効にしてください。既存のDAF・FAF設定も読み込めます。

画面上部の「ダーク」スイッチでライト／ダークを切り替えられます。ページを開いたときはライトで、OSやブラウザのテーマ設定には連動しません。

FAFはブラウザ内のAudioWorkletで再生速度を変えずに音程を変更します。−12〜＋12半音、0.5半音刻み。音声を外部へ送ったり録音保存したりしません。HTTPSまたはlocalhostと対応ブラウザが必要です。

操作画面は数値の直接入力とスライダー、A/Bの同時表示で調整できます。各項目のⓘにカーソルを近づけるかキーボードでフォーカスすると短い説明を表示し、クリック・タップすると固定できます。「詳しい説明」から操作を続けながら仕組みを確認できます。ガイドの「案内を見ながら試す」では任意の5ステップを確認できます。「使い方・仕組み」では、機能の操作、遅延と音程の違い、斉読やリズムの仕組み、研究結果と仮説、よくある質問、出典を紹介しています。ガイドの閲覧でマイクが起動することはありません。

「更新」「別名で保存」「複製」を分け、未保存の変更と元に戻す操作を表示します。サンプルは自分の保存設定に混ぜません。比較は保存設定・編集前・編集中・補助なしから選び、操作画面に進行と差分を表示します。任意の使用記録には開始条件と途中の設定変更が残り、場面で絞り込み、開始条件を読み戻せます。原稿編集後の古い句の再生を防ぎ、原稿表示へ切り替えられます。

比較を終了すると開始前の編集状態へ戻ります。比較中に条件を変えた場合は「比較条件から変更あり」と表示し、その使用は元の固定条件とは別の記録として扱います。使用中に「記録しない」を選んでも、その後の使用と設定変更は新しい一時記録で追跡します。音声の開始待ち中は設定入力を固定し、実際に開始した条件と使用記録を一致させます。

## 研究の根拠と出典

ガイドの「仕組みと研究結果」では、機能別に代表的な原著論文の対象人数・発話課題・結果・限界・本アプリとの差を確認できます。根拠は短期的な実験結果を中心とし、StutterSuite自体の有効性を証明するものではありません。出典と更新方針は [EVIDENCE_JA.md](EVIDENCE_JA.md) を参照してください。公開画面は追加のネットワークリクエストやマイク権限なしで読めます。

## 起動方法

Node.js を用意して、リポジトリのルートで次を実行します。

```bash
node server.js
```

ブラウザで `http://127.0.0.1:4174` を開いてください。

## プライバシーと安全

[安全・プライバシー・ライセンスと問い合わせ](https://stuttersuite.staryarn.dev/about.html)（同梱の [about.html](about.html)）。公開サイトはVercelで配信し、アクセスに伴う情報が処理されます。問い合わせメールはZohoで受信します。通常のアプリ利用と問い合わせ時の情報処理は区別しています。公開窓口は contact@staryarn.dev、開発・運営は [Staryarn](https://github.com/staryarn) です。

問い合わせの整理と提供者の確認は [運用メモ](OPERATIONS_JA.md) にまとめています。

マイク音声と原稿は、このアプリから外部サーバーへ送信しません。音声は処理中だけメモリで一時保持し、録音保存しません。補助停止でマイクを解放し、処理を終了します。TTSはブラウザがローカル音声として報告するvoice（`localService === true`）だけを利用します。ローカル音声が利用できない環境ではTTSを再生しません。設定や原稿、履歴はブラウザのローカル保存領域に保存されます。ブラウザ保存とJSONバックアップにアプリによる暗号化はありません。ヘッドホンを使い、OS・機器側も小さい音量から短く試してください。初期補助音量0 dBは相対値で、安全な音圧の保証ではありません。補助音量はTTSには適用されず、TTSの音量と出力先はOS／ブラウザで別に確認してください。緊急停止は補助音、マスキング、メトロノーム、TTSを停止し、マイクを解放します。通話アプリのミュートは別途操作が必要です。

## 開発・検証

Node.js 24で `npm test`。ブラウザ検証は最初に `npm ci` でテスト専用のElectron 44.5.1を取得し、`npm run test:browser` を実行します。画面を表示せず、音声出力とGPU利用を無効にし、実際の声を使わず合成入力で検証します。GitHub ActionsでもNodeテストとブラウザテストを実行します。Electronは本アプリの実行や公開には不要です。実装と検証の範囲は [WEB_IMPLEMENTATION_JA.md](WEB_IMPLEMENTATION_JA.md) を参照してください。

バックアップは2 MiBまで、原稿は50,000文字、設定は100件、句と履歴は各2,000件、メモは10,000文字までです。読み込みデータは検証・移行後に保存し、不正なデータや保存失敗で元データを置き換えません。保存データが壊れているか将来の形式だった場合は上書きを止め、元データの書き出し・正常なバックアップの復元・削除を案内します。保存容量不足時は未保存の内容もバックアップへ書き出せます。

緊急停止のショートカットは、このタブにフォーカスがあるときだけ有効です。別アプリを操作中のOS全体ショートカットはWeb版では提供しません。緊急停止ボタンまたはショートカットは、同じブラウザ・同じサイトの他タブへ停止を通知します。別のブラウザやプライベートウィンドウには伝わりません。説明・保存・比較が開いているときのEscは、それを閉じるだけです。その間もCtrl+Alt+F12で緊急停止できます。マイク切断や音声処理エラーによる自動停止、タブを閉じる操作は他タブを停止しません。出力先の切替は順番に処理し、切替中と補助の開始中は選択を一時的に無効にします。切替失敗時は実際の出力先の選択へ戻します。

`vercel.json` にCSP（`frame-ancestors 'none'`）、X-Frame-Options、nosniff、Referrer-Policy、Permissions-Policyを設定しています。マイクと出力機器の選択は同じサイトで許可します。ローカルサーバーも同じヘッダーを使います。公開反映後は実際の応答ヘッダーも確認してください。

Vercelでは依存インストールをスキップし、テスト用Electronを取得しません。ローカル配信用server.jsとテスト・lockfileは静的配信から除外します。
